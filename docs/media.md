# Media / screenshots

The original project evidence is retained under `screenshots_project/`.

| Current filename | Descriptive meaning |
|---|---|
| `systolic_array_architecture.jpeg` | High-level systolic-array architecture and dataflow |
| `schematic.jpeg` | Synthesized RTL schematic / hierarchy evidence |
| `simulation.jpeg` | RTL simulation waveform / cycle behavior |
| `implementation.jpeg` | Vivado implementation/design-view evidence |
| `utilization_rpt.jpeg` | FPGA resource utilization report |
| `timing_rpt.jpeg` | Timing analysis report |
| `power_rpt.jpeg` | Power analysis report |
| `training_py.jpeg` | Python model/training flow evidence |
| `inference_py.jpeg` | Python inference/reference-model evidence |
| `uvm_tests.jpeg` | Historical verification evidence retained from project development |

Each file is linked from the README by its purpose (architecture, verification, or implementation evidence) rather than left as an undifferentiated screenshot directory.
